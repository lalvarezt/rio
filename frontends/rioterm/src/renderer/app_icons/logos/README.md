# Bundled brand marks

`openai.svg` and `claude.svg` are unchanged copies of Microsoft's Codicons.

  [claude.svg](https://github.com/microsoft/vscode-codicons/blob/main/src/icons/claude.svg).

The renderer scales and tints the marks at runtime; the SVG source is unmodified.
